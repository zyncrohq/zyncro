## 🚀 Quick Start

Run directly with `npx` or `pnpm dlx` or `yarn create`:

```bash
npx create-zyncro-app my-app
# or
pnpm create zyncro-app my-app
# or
yarn create zyncro-app my-app
# or
bun create zyncro-app my-app
```

---

## ⚡ What's Included?

- 📅 **Pre-configured Zyncro SDK**: Ready-to-use client with `@zyncro/sdk`.
- ⚛️ **Next.js & React Embeds**: Pre-built calendar components with `@zyncro/react`.
- 🪝 **Webhook Handlers**: Built-in endpoints for instant booking sync and payment receipts.
- 🎨 **Tailwind CSS & Dark Mode**: Sleek, modern scheduling UI out of the box.
